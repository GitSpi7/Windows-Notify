# Windows Notify

Нативное Windows 11 desktop-приложение для фонового мониторинга событий операционной системы Windows (блокировка, разблокировка, вход, выход, завершение работы) и мгновенной отправки email-уведомлений через почтовый сервис **SMTP**.

## Описание

**Windows Notify** — это легковесный системный агент для ОС Windows 10/11, работающий в фоновом режиме в системном трее. Приложение регистрирует ключевые события сессии пользователя и выключения компьютера, немедленно формируя и отправляя оповещения на указанный адрес электронной почты. Это позволяет контролировать физический и удаленный доступ к рабочей станции или серверу.

## Технологии

- **.NET 8** (C# 12) — современная платформа с высокой производительностью
- **WPF (Windows Presentation Foundation)** — графический интерфейс с нативной интеграцией Windows
- **MailKit (v4.16.0)** — надежная кроссплатформенная библиотека для отправки почты по протоколам SMTP/SSL/TLS
- **H.NotifyIcon.Wpf (v2.1.3)** — поддержка системного трея Windows 10/11 с контекстным меню
- **CommunityToolkit.Mvvm (v8.2.2)** — реализация паттерна MVVM с использованием source generators (`[ObservableProperty]`, `[RelayCommand]`)
- **System.Security.Cryptography.ProtectedData (DPAPI)** — аппаратная привязка шифрования учетных данных к профилю пользователя Windows
- **Serilog & Serilog.Sinks.File** — структурированное ротируемое логирование без сохранения чувствительных данных
- **Microsoft.Extensions.Hosting** — управление жизненным циклом и Dependency Injection (DI)

## Возможности

1. **Мониторинг 6 типов системных событий (на русском языке):**
   - **Включение ПК** (Startup — фиксация старта системы / включения компьютера)
   - **Выключение ПК** (Shutdown — выключение или перезагрузка системы с блокировкой преждевременного отключения сети через `ShutdownBlockReasonCreate`)
   - **Вход в систему** (Logon — вход пользователя в Windows)
   - **Выход из системы** (Logoff — завершение сеанса текущего пользователя)
   - **Блокировка системы** (Lock — `Win + L`, автоблокировка по тайм-ауту)
   - **Разблокировка системы** (Unlock — успешный ввод пароля/PIN/Windows Hello)
2. **Отображаемое имя компьютера:**
   - Настройка пользовательского имени ПК в параметрах (подставляется в тему и тело письма; по умолчанию используется системное имя `Environment.MachineName`).
3. **Призрачный режим (Ghost Mode):**
   - Возможность скрыть значок из системного трея прямо через меню иконки.
   - Механизм Single Instance (`Mutex` + `EventWaitHandle`): при клике по ярлыку на рабочем столе или в меню «Пуск» открывается меню и главное окно уже работающего процесса.
4. **Интеграция с Yandex SMTP:**
   - Быстрая и безопасная отправка уведомлений через защищенное соединение (SSL/TLS).
   - Поддержка отдельного адреса получателя (или отправка самому себе).
5. **Безопасное хранение учетных данных:**
   - Пароль приложения никогда не хранится в открытом виде — используется шифрование Windows Data Protection API (DPAPI).
6. **Автозагрузка:**
   - Возможность автоматического запуска вместе со стартом Windows через реестр текущего пользователя (`HKCU`).
7. **Строгая очередь сообщений (FIFO Queue):**
   - Полное устранение дубликатов писем с уникальными идентификаторами (GUID).
   - Строгая очередность отправки: события никогда не обгоняют друг друга при временном отсутствии связи.
   - Автоматическая мгновенная отправка при подключении к сети.
8. **Индикатор состояния:**
   - Отображение статуса мониторинга, состояния сетевого подключения и счетчика неотправленных писем в очереди.

## Настройка на примере Yandex Почты

Для отправки писем через Yandex требуется специальный **пароль приложения**. Обычный пароль от учетной записи Yandex использовать нельзя (и небезопасно).

Выполните следующие шаги:

1. **Включите доступ по протоколам почтовых клиентов:**
   - Откройте [Яндекс Почту](https://mail.yandex.ru/) в браузере.
   - Перейдите в **Все настройки** (значок шестеренки) → **Почтовые программы**.
   - Убедитесь, что включена галочка **С сервера по протоколу IMAP** (или разрешение для почтовых клиентов) и сохраните изменения.

2. **Создайте пароль приложения:**
   - Перейдите на страницу управления аккаунтом: [id.yandex.ru](https://id.yandex.ru/).
   - Откройте раздел **Безопасность**.
   - Найдите блок **Пароли приложений** и нажмите кнопку добавления.
   - Выберите тип приложения: **Почта**.
   - Придумайте понятное имя (например, `WindowsNotify-Desktop`) и нажмите **Создать**.
   - Скопируйте сгенерированный 16-значный пароль приложения (он показывается только один раз).

3. **Укажите данные в Windows Notify:**
   - Запустите приложение **Windows Notify**.
   - В поле **Email отправителя** укажите ваш адрес Яндекс (например, `username@yandex.ru`).
   - В поле **Пароль приложения** вставьте скопированный пароль.
   - При необходимости укажите отдельный **Email получателя**.
   - Нажмите кнопку **Тест отправки** для проверки связи. После успешного теста нажмите **Сохранить**.

## Сборка проекта

Для компиляции проекта выполните стандартные команды .NET CLI в терминале:

```powershell
# 1. Клонирование репозитория и переход в директорию проекта
cd c:\Users\User\Documents\Uvedom

# 2. Восстановление зависимостей NuGet
dotnet restore

# 3. Сборка в конфигурации Release
dotnet build -c Release --no-restore

# 4. Публикация автономной (self-contained) сборки под Windows x64
dotnet publish src/WindowsNotify/WindowsNotify.csproj -c Release -r win-x64 --self-contained true -o publish/
```

Флаг `--self-contained true` упаковывает среду выполнения .NET в выходную директорию `publish/`, благодаря чему приложение работает на любом компьютере с Windows 10/11 без необходимости предварительной установки .NET Runtime.

## Установка

Для создания удобного дистрибутива используется **Inno Setup 6**:

1. Установите [Inno Setup 6](https://jrsoftware.org/isdl.php).
2. Выполните публикацию приложения в папку `publish/` (см. раздел [Сборка](#сборка-проекта)).
3. Скомпилируйте скрипт установщика:
   - Через GUI Inno Setup: откройте `installer/WindowsNotifySetup.iss` и нажмите **Build → Compile**.
   - Через командную строку:
     ```powershell
     "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\WindowsNotifySetup.iss
     ```
4. В папке `installer/` будет создан файл `Windows Notify Setup.exe`.

### Особенности инсталлятора:
- **Без прав администратора (`PrivilegesRequired=lowest`):** Устанавливается в пользовательскую директорию `%LOCALAPPDATA%\Programs\WindowsNotify`, не требуя повышенных привилегий UAC.
- **Опция автозапуска:** Создает ключ в ветке реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- **Полная локализация:** Интерфейс инсталлятора полностью на русском языке.
- **Чистое удаление:** При деинсталляции корректно удаляются программа, созданные логи и файлы локальной очереди.

## Запуск и аргументы командной строки

Приложение поддерживает запуск с дополнительными параметрами:

- **Стандартный запуск:**
  ```powershell
  WindowsNotify.exe
  ```
  Открывает главное окно настроек и журнала событий.

- **Запуск в свернутом виде (для автозагрузки):**
  ```powershell
  WindowsNotify.exe --minimized
  ```
  Приложение запускается сразу в системный трей без отображения главного окна на экране. При двойном клике по иконке в трее открывается окно настроек.

│   │   ├── INotificationService.cs# Системный трей и всплывающие подсказки
│   │   ├── ISettingsService.cs    # Чтение и запись конфигурации

├── ViewModels/                    # Модели представления (CommunityToolkit.Mvvm)

## Безопасность

- **Шифрование DPAPI:** Пароль приложения Yandex шифруется системным API Windows (`ProtectedData.Protect` с областью `DataProtectionScope.CurrentUser`). Ключ шифрования привязан к учетной записи Windows и не может быть расшифрован другим пользователем или на другом компьютере.
- **Отсутствие паролей в конфигурационных файлах:** В файле настроек `AppSettings.json` пароли никогда не сохраняются.
- **Безопасные логи:** Подсистема логирования Serilog сконфигурирована таким образом, чтобы ни при каких условиях не записывать пароли, токены или заголовки авторизации в лог-файлы.
- **Защита от утечек в UI:** Поле ввода пароля использует защищенный элемент управления WPF `PasswordBox`.

## Известные ограничения

> [!IMPORTANT]
> ### Поведение при выключении компьютера (Shutdown)
> 
> При выключении или перезагрузке операционная система Windows отправляет процессам системные уведомления `WM_QUERYENDSESSION` / `SessionEnding`. После этого Windows выделяет процессам **ограниченный интервал времени** (таймаут завершения работы, обычно не превышающий нескольких секунд) на сохранение данных, после чего принудительно убивает процесс (`TerminateProcess`).
> 
> Кроме того, в момент выключения Windows сетевой стек (Wi-Fi, сетевые адаптеры, DNS-клиент) может начать деинициализацию параллельно с завершением процессов.
> 
> **Как работает Windows Notify:**
> 1. При перехвате события `Shutdown` приложение применяет стратегию **best-effort**: немедленно формирует письмо и запускает отправку через Yandex SMTP с жестким таймаутом **5 секунд**.
> 2. Одновременно событие гарантированно фиксируется в локальной энергонезависимой очереди на диске (`queue.json`).
> 3. Если за отведенный квант времени письмо успевает уйти на сервер — запись удаляется из очереди.
> 4. Если сеть уже недоступна или Windows форсированно завершает процесс до завершения сетевого сокета — письмо остается в очереди.
> 5. При следующем включении компьютера и запуске Windows Notify приложение обнаруживает неотправленные письма и **автоматически отправляет их**, с сохранением точного времени, когда выключение фактически произошло.
> 
> **Это НЕ является багом приложения**, а представляет собой фундаментальное архитектурное ограничение операционной системы Windows при завершении работы.
